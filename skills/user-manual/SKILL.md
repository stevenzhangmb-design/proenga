# User-Manual Skill — 操作手册

## 触发场景

| 触发 | 示例 |
|---|---|
| 原型确认后 | "原型 OK 了，出操作手册" |
| 显式指令 | "生成操作手册 / 出用户手册 / 写操作指南 / 给最终用户的文档" |
| 同步更新 | "原型改了，操作手册更新一下" |

## 输入（单一真理源）

1. **prd-data.json** —— 菜单 + 字段 + 用例规则
2. **原型 HTML**（截图占位参考）

## 输出

`./archive/操作手册-<模块名>-<日期>.md`（单文件）

## 文档结构（标准模板）

```markdown

- 适用版本：v1.0
- 编写日期：YYYY-MM-DD

## 2. 模块概述
- 业务目的（这个模块是做什么的，能解决什么问题）

## 3. 功能介绍
（按 menus 结构，每个功能点一节）

### 3.1 <功能点 1：查询>

**功能说明**：用一句话告诉用户这个功能能做什么。

**操作步骤**：
1、第 1 步：进入「<完整菜单路径>」
   [截图占位：列表页]
2、第 2 步：在筛选条件区输入查询条件
   - 等级名称：模糊匹配（可输入部分名称）
   - 状态：选择启用 / 停用 / 全部
3、第 3 步：点击「查询」按钮，系统按条件刷新列表
   [截图占位：查询后列表]
4、第 4 步：（可选）点击「重置」按钮清空所有条件

**操作结果**：列表显示符合条件的数据。

**注意事项**：
- 等级名称支持模糊匹配（输入"金" 可匹配"金卡"和"黄金卡"）
- 状态为"全部"时显示所有数据（含已停用）

### 3.2 <功能点 2：新增>

**功能说明**：新建一条会员等级数据。

**操作步骤**：
1、第 1 步：在列表页点击「新增」按钮
   [截图占位：新增按钮]
2、第 2 步：在弹出的对话框中填写表单字段
   - 等级编号：自动生成（如 VL0005），不可修改
   - 等级名称：必填，1~30 字符，同体系内唯一
   - 升级阈值：必填，范围 ¥0~999999.99，必须大于上一级等级
   - 权益描述：选填，最多 200 字
   - 状态：必填，默认"已启用"
   [截图占位：新增弹窗]
3、第 3 步：填写完成后点击「保存」按钮
4、第 4 步：在二次确认对话框中点击「确认」
   [截图占位：确认对话框]
5、第 5 步：系统提示"新增成功"，新数据出现在列表顶部

**操作结果**：列表新增一条会员等级数据，可在列表查询到。

**注意事项**：
- 如果某字段填写不规范，离开该字段时会在下方显示红色错误提示
- 如果点击取消或关闭弹窗（× / ESC），数据不会保存

## 4. 常见问题（FAQ）

**Q1：删除时提示"该等级有 N 个关联会员，不可删除"怎么办？**
A：先把这些会员迁移到其他等级，或先停用该等级（停用后新会员不会再选择，但已有会员保留）。

**Q2：升级阈值填写时提示"已存在等级阈值=¥XXXX"是什么意思？**
A：系统要求每个等级的升级阈值唯一，请改一个不冲突的数值。

**Q3：编辑后数据没保存怎么办？**
A：可能是因为：① 校验未通过（看字段下方红字提示）② 网络异常 ③ 点了取消。请重新填写并确认保存。

**Q4：状态从"已启用"切到"已停用"，已有会员怎么办？**
A：已有会员保留在该等级，但新注册会员不可选择。

## 5. 故障排查

| 现象 | 可能原因 | 解决方法 |
|---|---|---|
| 列表不显示数据 | 筛选条件过严 | 点重置或清空条件 |
| 按钮点击无反应 | 网络异常 / 权限缺失 | 刷新页面 / 联系管理员 |
| 字段填写时无法保存 | 校验未通过 | 看字段下方红字提示，修正后重试 |

## 6. 操作日志查询

每次成功操作（新增 / 编辑 / 删除 / 启用 / 停用），系统会自动记录：
- 操作时间 / 操作账号 / 操作模块 / 操作功能 / 操作明细 / IP地址

如需查询操作记录，请进入「设置 → 操作日志」。

## 7. 联系支持

如遇问题：
- 技术支持：[support@example.com]
- 工单系统：[ticket.example.com]
- 服务时间：工作日 9:00-18:00
```

## 与 prd-data.json 的映射规则

| prd-data.json 内容 | 对应手册内容 |
|---|---|
| `menus` 结构 | §2 模块入口（导航路径）|
| 功能点 fp_name | §3 各章节标题 |
| `field_specs.groups[].fields[]` | §3 操作步骤中字段填写说明 |
| `field_specs[].constraint` | §3 字段填写规则（人话化）|
| `use_cases.operation_flow` | §3 操作步骤逐步 |
| `use_cases.postconditions` | §3 操作结果 |
| `use_cases.validations` | §3 注意事项 + §4 FAQ |
| `use_cases.prompt_messages` | §5 故障排查（字段提示对应解法）|
| `use_cases.operation_log` | §6 操作日志说明 |

## 同步更新机制

**原型改了 → 必须重跑本 skill**：
1. 对比 prd-data.json 变更
2. 重新生成全文（操作手册重做成本低，全量重写更稳）
3. 文档头加变更日志：哪些章节内容变了 / 哪些截图需要重拍

## 适用产品形态

任何产品形态都适用。按业务对象 / 用户角色自动调整说明语言风格。

## 规范遵守

遵守 [pm-design/v1-master-spec.md](../pm-design/v1-master-spec.md) 的单一真理源原则。
