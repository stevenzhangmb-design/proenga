## 4. 常见问题（FAQ）

### Q1：保存时提示"<字段名>已存在"怎么办？

**原因**：系统要求 <字段名> 唯一，已有相同值存在。

**解决**：
1. 通过查询确认是否有同名的数据
2. 如确实重复，请改一个不同的名称
3. 如怀疑数据错误，请联系管理员排查

---

### Q2：删除时提示"有 N 个关联，不可删除"怎么办？

**原因**：当前 <对象> 被其他数据引用，不能直接删除。

**解决**：
1. 先将关联数据迁移到其他 <对象>
2. 或先「停用」该 <对象>，避免新关联产生
3. 等所有关联清零后再删除

---

### Q3：填字段时下方一直显示红字，无法保存怎么办？

**原因**：字段校验未通过。

**解决**：
1. 仔细阅读红色提示文字
2. 按提示规则修改输入
3. 确认所有字段都通过校验（无红字）后才能保存

---

### Q4：列表显示不全或没有数据？

**可能原因**：
- 筛选条件过严
- 数据被停用，被默认筛选排除
- 无查看权限

**解决**：
1. 点「重置」清空筛选
2. 状态筛选选"全部"
3. 联系管理员检查权限

---

### Q5：操作日志在哪里查看？

**进入路径**：`<设置 → 操作日志>`

**支持筛选**：按操作时间、操作人、操作模块、操作类型筛选

---

### Q6：忘记密码怎么办？

1. 在登录页点击「忘记密码」
2. 输入注册手机号 / 邮箱
3. 通过短信 / 邮件接收验证码
4. 设置新密码

如仍有问题，请联系管理员重置密码。

## 5. 故障排查

| 现象 | 可能原因 | 解决方法 |
|---|---|---|
| 页面打不开 / 白屏 | 网络问题 / 浏览器缓存 | 检查网络 + Ctrl+F5 强制刷新 |
| 按钮点击无反应 | 浏览器版本过低 / JS 错误 | 升级浏览器到最新版 |
| 数据不显示 | 筛选过严 / 无权限 / 数据为空 | 重置筛选 / 联系管理员 |
| 保存失败 | 字段校验未通过 / 网络中断 | 看红字提示 / 检查网络重试 |
| 提示"会话已过期" | 长时间未操作 / Token 失效 | 重新登录 |
| 数据看不全 / 显示乱码 | 浏览器编码问题 | 检查编码 UTF-8 |
| 文件下载失败 | 文件过大 / 网络中断 | 改用更稳定的网络 / 分批下载 |

如以上方法不能解决，请提交工单或联系技术支持。
