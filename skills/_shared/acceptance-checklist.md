# 验收铁律清单（Acceptance Checklist · 随包·跨工具）

> **用途**：这是 Proenga 的**验收红线**。无论在本地哪个 AI 对话框、还是打包后别人用其他 AI 工具（Cursor / Codex / OpenClaw / Copilot 等）调用这些 skill，**都必须达到以下效果**。
> **给宿主 AI 的话**：如果你（任何 AI 工具里的 AI）执行画原型 / 生成 PRD / 标注 / 导出分享版 / 清空恢复 / 导出研发版时，行为与本清单不符——**请读全对应 skill 规则（pm-design / prd / 对应 qa 机器闸），照规则自行修复，跑机器闸验绿再交付**。不要绕过、不要降级、不要静默失败。
> **验证方式**：不空口保证。任何改动交付前必跑 `pm-design/qa/deliver-gate.js` 全绿 + 涉 UI 必截图眼验。

---

## 一、画原型（严格遵循 pm-design skill）

- [ ] 每次画原型，**动手前先弹四问**：① UI 风格（默认 system-design-spec / 用户参考）② 端/形态（B端后台走 `system-design-spec.md`、移动版走 `system-design-spec-mobile.md`）③ 地区/币种/时区 ④ **支持哪些语言**（单语中文 / 中英葡 / 中英葡西；默认显示哪种）。禁止不问就直接套默认开画。
- [ ] 选"默认"→ 严格照对应设计规范落地，不自创、不简化。
- [ ] 选**多语** → 顶栏出语言切换器；每条文案（含 `custom` 复杂页整块 HTML）写成 `{"zh":…,"en":…,"pt":…}`；表格 mock 业务数据**不翻译**；`region=BR` 必须含 `pt`。缺译由 `i18n-completeness-gate.js` 逐条点名判红。
- [ ] **圈选 / 生成 PRD 一律以中文为准**：开启标注自动切回中文并提示，标注开启期间语言锁定（骨架强制）。

> 🏛 **为什么圈选要锁中文**：标注层采集的是**当前 DOM 上显示的文字**。葡语下圈选会把 `fp_name` 写成 `Lista de NF`，
> 葡语功能名混进中文 PRD，同一功能还会因语言不同被圈成两个 PIN。`fp_key` 语言无关，会漂的是 `fp_name` / `zoneLabel`。

## 二、原型顶部标注栏

- [ ] **默认标注不开启**（进原型时是关的）。
- [ ] 开启标注后，顶部显示这几项：**复制已圈功能 · 导出分享版 · 清空 · 恢复标注**。
- [ ] **导出分享版** 四条：
  - [ ] ① 没做任何功能标注**也能导出**。
  - [ ] ② 做了功能标注**也能导出**。
  - [ ] ③ 别人打开分享版：**只能看标注、默认开启显示**，其他功能都没有（只读）。
  - [ ] ④ 导出时**必须保存得下来，且能选择保存位置**（2026-07-10 精确化，见下方浏览器兼容说明）：
    - [ ] **Chromium 系（Chrome/Edge）+ `localhost` 或 `https://`** → 弹原生「另存为」框，可自选文件夹。
    - [ ] **其它环境**（双击打开的 `file://`、Firefox、Safari）→ 浏览器**不支持/禁止**该 API，**必须自动退回下载**，并明确告知"这是浏览器限制、不是失败"+"想自选位置请开启浏览器「下载前询问每个文件的保存位置」"。
    - [ ] 🔴 **任何情况下都不得误报「已取消保存」而实际什么都没保存**——只有用户**真的点了取消**才允许提示「已取消保存」。
      > 判据：`showSaveFilePicker` 抛的 `AbortError` 有歧义（用户取消 / 框根本弹不出来）。用**耗时**区分：人开框再点取消不可能 <300ms；框弹不出来是瞬时 reject。
      > 历史：此条曾长期是坏的（永远提示"已取消保存"），而 ㉚ 闸因**注入假 picker** 一直判绿 → 已加静态断言 ④/④-b 焊死。
- [ ] **清空 / 恢复标注**：深度检查，行为正常——清空只隐藏（不毁 prd-data），恢复能从真理源重新注入，二次确认在。

## 三、生成 PRD 的核心（严格遵循 prd skill）

- [ ] **1（圈选→对话框生成）**：原型里点选/圈选功能范围→复制到 AI 对话框→AI 严格按 prd 全部规则生成 PRD→内容**完整同步回已圈选的标注**，**同时本地完整生成 PRD**；**自动截图、流程图不受影响**。
- [ ] **2（双向编辑/删除同步）**：在原型标注里编辑/删除功能名、字段规范、用例规则→保存→**自动同步到本地 PRD**；在 AI 对话框里编辑/删除→也**自动同步回原型标注 + 本地 PRD**。两个方向都通。
- [ ] **3（增量圈选）**：已生成 PRD 后，还能在原型里再圈新功能→复制到对话框→按 prd 规则**本地 PRD 更新的同时，新标注也自动显示**。
- [ ] **4（纯对话框生成）**：不点选/不圈选，直接在对话框生成 PRD→本次**自动同步到原型标注 + 本地生成 PRD**；**自动截图、流程图不受影响**。

> 🏛 **【圈选后 PIN 是空的 = 正确行为，不是缺陷】（B 架构·验收时别误判）**
> **圈选/点选只圈范围**，客户端**不生成任何 PRD 内容** → 新 PIN 里字段规范/用例规则**就是空的**（显示"待生成"）。
> 内容要点【复制已圈功能】→ 粘到 AI 对话框 → AI 按 prd skill **真推理**生成 → 回填 PIN + 落本地 PRD。
> ⛔ 验收时看到"圈完没内容"**不算 bug**；⛔ 任何 AI **不得**在客户端重新实现启发式草稿生成（`anno-fix-guard` 断言 ⑥⑦ 判红）。
> 历史：客户端曾内嵌 650 行模板猜内容 → 质量差、拆东墙补西墙、跑不通，2026-07-09 已整段删除。

## 四、跨工具（打包后·别人用其他 AI 工具）

- [ ] 打包后用户安装，在**其他 AI 工具**（一个或多个对话框）里调用这些 skill 做：画原型 / 生成 PRD / 开启标注 / 导出分享版 / 清空 / 恢复标注 / 导出研发版 等操作。
- [ ] 若该 AI 工具上行为不对，**让那个 AI 读本仓库已有的 skill 规则 + 机器闸，自行修复**——这依赖：规则随包（skills/）、机器闸随包（qa/）、本清单随包。**单一真理源 + 机器闸兜底**是跨工具一致性的保证机制。

## 附则 A · 技术栈的确认时机（2026-07-09 架构修订 · 旧的"三问定技术栈"作废）

> **铁律**：**画原型四问只问 ① UI 设计规范　② 端/形态　③ 地区/币种/时区　④ 语言——不问技术栈。**
> 技术栈（前端 + 后端）**只在点【导出研发版】时才确认**，因为它到那一步才用得上。

**导出研发版流程（任何 AI 工具都按此执行）**：
1. **前提**：原型 + PRD 已完成，且 **PRD 填全**（字段规范 + 7 节用例规则）。PRD 空/糙 → 出的料必是垃圾（GIGO），应拦住先补 PRD。
2. **触发**：原型点【导出研发版】按钮　或　AI 对话框说"导出研发版"（对话框驱动需按 `system_name` 定位是哪个项目）。
3. **确认**：提示「**确认采用默认的技术方案吗？**」
   - 默认栈**按 `__DESIGN_CHOICE__.form` 动态显示**：B端 → 后端 Java 四层 + 前端 Vue3+EP；移动版 → uni-app+uv-ui+rpx。**禁写死 B 端栈**。
   - 若此前已学过用户的栈 → 改问「**采用你上次的技术栈〔X〕吗？**」
4. **分叉**：
   - **选「是」** → 按 `_shared/dev-stack-spec.md` 直接出料，零追问。
   - **选「否」** → **先学栈**：用户发前/后端代码/框架文档 → AI 提取范式（分层/框架/DDL风格/错误码/i18n/契约）→ 存 `learned-stack/<名>` → **学完才执行导出**。
5. **按钮 + 选「否」= 断点**：按钮是机械的、不会学 → 必须提示「**请到 AI 对话框把技术栈发过去**」，学完再回来导。
6. **出料**（不出代码）：`openapi.yaml` + `schema.sql` + `tokens.css` + `prompts/前后端.md` + `README.md`。
7. **已学过的栈下次沿用**，不重学（除非用户说"换栈"）。

> 🔜 **诚实状态（2026-08-16 更新）**：已做出 **MVP，分两个按钮**——📦【导出对接料·喂AI】（Route A：出 `openapi.yaml`+`schema.sql`+`tokens.css`+`prompts/前后端.md`+`README.md`，栈无关，喂任意 AI）＋🚀【一键生成代码】（Route B：确定性生成前后端骨架，弹窗选栈 前端 Vue/React × 后端 Java/Node/Python = 6 组合，主子表支持，`codegen/` 生成器 + `codegen-smoke-gate.js` 护栏）。**天花板 L3：CRUD/主子表/契约齐，复杂业务逻辑约 20% 仍是 TODO 待人补**（原型/PRD 里没有的规则，生成器造不出）。本附则的"选栈时机 / 学栈流程"仍适用于两个按钮。

> **配套机器闸**（产品自保，非客户依赖）：`pm-design/qa/deliver-gate.js`（总闸）· 原型合规闸 · 原型↔标准件漂移闸 · 注入回路闸等。交付前跑绿是本清单每一条的"证据"，替代口头保证。

> ⚠️ **闸绿 ≠ 没问题**：闸只能抓它被教会的东西。若用户报了现象而闸判绿，**先怀疑闸有盲区**（假实现、硬编码像素/标识符、覆盖不全）。修复纪律与回流机制见 [`fix-and-upstream-protocol.md`](./fix-and-upstream-protocol.md)。
