## 📌 输出规范

### Markdown 输出格式

每页用 `## P<编号>` 标题分隔，含：
- 布局描述（用文字 + 示意符号画结构）
- 内容文案
- 数据点
- 图表占位（用 [图表占位：XX] 标记）

### 量化数据获取来源

| 数据 | 来源 |
|---|---|
| 公司数据（用户/数据量/融资）| 用户输入 |
| 客户数据（行业平均）| AI 行业知识库 |
| 系统数据（功能数/接口数）| prd-data.json 统计 |
| 效果数据（X% 提升）| 业务背景估算 + 标注"行业平均"|

### 内容深度自适应

| 项目规模 | 推荐页数 | 减少哪些页 |
|---|---|---|
| 小型（5-8 模块）| 20-25 页 | 部分功能亮点页合并 |
| 中型（10-15 模块）| 28-34 页 | **行业标杆 WMS 标准** |
| 大型（20+ 模块）| 35-45 页 | 加更多生态对接 / 案例页 |
