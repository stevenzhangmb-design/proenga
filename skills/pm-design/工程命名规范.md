# 工程命名规范（功能名 fp_name 单一真理源）

> **本文件是"功能名怎么取才合格"的唯一真理源。** 任何 AI 工具（本地 / Cursor / Codex / OpenClaw）在**提炼、生成、优化功能名（fp_name）之前必须先读本文**。
> 规则的**可执行形态** = [`qa/function-name-gate.js`](qa/function-name-gate.js) 的 `checkName()`；anno-server `checkFnName()` 是其部署副本。**三处改任一必同步另两处。**

## 一句话

**功能名 = 用户能看懂的"动宾式功能"或"业务实体名"，不是数据值、不是兜底词、不是整句话。**

## 合格（✓）

| 类型 | 例子 |
|---|---|
| 动宾式功能 | 新增采购单、导出对账单、审核充值、批量导入 |
| 单动词按钮 | 导出、编辑、删除、查询、审核、充值、导入、查看 |
| 业务实体/区域名 | 门店对账、账户余额 (BRL)、消息通知/消息公告、一件代发/B2B/退货 |

## 禁用（✗·硬卡·命中任一直接判红，不许写进 PRD、不许交付）

| # | 禁用类型 | 反例 | 为什么错 |
|---|---|---|---|
| ① | 纯编号 / 纯数字 / 单号 | `PTKFX260806009`、`1`、`20260806009` | 取到了**数据值**，不是功能 |
| ② | 通用兜底词 | `功能区`、`列表`、`操作`、`区域`、`未命名`、`卡片`、`内容` | **没取到真名**，用了占位兜底 |
| ③ | 营销句 / 说明整句 | `连接你的商店体验更多功能`、`欢迎使用立即开始` | 是**整段文字**，不是功能名 |

判定细则（与 `checkName()` 一致）：纯数字 / `^[A-Za-z]{0,8}[-_]?\d{5,}` 编号 / 命中兜底词表 / 长度>20 / 含中文标点（，。！？；）/ 长度≥8 且含营销引导词（你 您 我们 更多 体验 欢迎 立即 …）→ 一律红。

## 两处硬卡（在名字**入库那一刻**和**交付前**各卡一道）

1. **源头**：anno-server `/anno-inject` 落名前 `checkFnName(pin.title)`，坏名回 **HTTP 422 + 原因**，拒写进 `prd-data.json`。浏览器收到 422 → 弹原因 + 自动打开 ✏️改名框。
2. **交付**：[`qa/function-name-gate.js`](qa/function-name-gate.js) 挂在 deliver-gate（㊴），扫 `prd-data.json` + 原型内嵌 `__PRD_DATA__` 的全部 `fp_name`，有坏名 → 交付总闸红。

## 与既有命名闸的分工（不冲突）

- **㊴ 工程命名硬卡（本规范）**：**垃圾名**（三类禁用）一律拒。
- **⑲ 功能名忠实**：AI 不许把**已经合格的名**擅自改名 / 缩写 / 优化——照圈选原名。（用户亲手改名 `isAIDraft=false` 豁免；圈选名本就是泛化兜底词时豁免 → 交给 ㊴。）
- **⑱ 系统归属**：功能归真实 OMS/WMS，禁通用兜底。

## 遇到坏名怎么办（AI 的 SOP）

1. **别用兜底词/数据值凑数**。名字取不到真名时，从圈选抓到的**真实内容**（zoneTexts / 菜单路径 / 区块标题）里找真功能，faithful 地取——不是自己发明、也不是把好名"优化"成别的（那会踩 ⑲）。
2. 实在判断不了 → **留给用户 ✏️改名**，别硬塞一个坏名进 PRD。
3. 用户改名（`isAIDraft=false`）**永远优先**，是最终真值。
