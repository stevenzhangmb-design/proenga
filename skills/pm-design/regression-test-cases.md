# 标注层回归测试用例清单（regression-test-cases）

> **用途**：本清单是「标注层 annotation-layer 代码每次改动后必跑的回归检查」。
> 每修一个 bug 就在此追加一条用例；改完代码后逐条核对 PASS，防止「修了又犯」。
> **工具无关**——任何 AI 工具 / 维护者都能照此核对，不依赖特定运行环境。
>
> 🚦 **首选自动回归闸（强制）**：`node skills/pm-design/qa/regression-check.js [原型路径]` —— 零依赖
> （node 内置 + 本机 Chrome headless/CDP），一键跑完核心断言（解耦 / 双实例桥接 / 字段双层 /
> 用例规则 7 节 + 1.2.3 编号 / 提示消息表·消息通知4列·操作日志6行 / 崩标注层业务存活 / 0 真实报错），
> **退出码 0=全绿才算改完**。下方手工清单作为补充与断言来源；**新发现的坑：先往脚本加断言，再修**。

---

## 核对方式

- 打开对应原型 HTML，按用例「操作」列执行（**框** = 右键拖拽框选；**点** = 右键单点元素）。
- 对照「预期结果（PASS 标准）」逐项检查。
- 「曾经的错误（防回归）」列出此前真实犯过的错，若结果落到该列即判 **FAIL**。

## 用例清单

### RT-01　OMS 框「账户余额卡」→ 必须命中只读余额展示

| 项 | 内容 |
|---|---|
| **场景** | OMS 首页右侧顶部的「账户余额」展示卡（只读：账户余额 / 充值总额 / 消费总额 / 最后更新） |
| **操作** | 右键**框选**整张账户余额卡 |
| **预期结果（PASS）** | fp = `账户余额-OMS.首页右侧顶部`；内容为只读余额展示，字段含「账户余额 / 充值总额 / 消费总额 / 最后更新」；**无币种筛选、无客户多选** |
| **曾经的错误（防回归）** | ① 错配成 `账户余额-WMS.查询`（仓库端看全部客户）；② 错配成 `账户余额-OMS.查询`（列表页带币种筛选）。两者都判 FAIL |

### RT-02　框「含『充值』按钮的账户余额卡」→ 区域名取卡片标题，不取按钮名

| 项 | 内容 |
|---|---|
| **场景** | 账户余额卡内嵌有「充值」按钮 |
| **操作** | 右键**框选**整张卡（框内含「充值」按钮） |
| **预期结果（PASS）** | 区域名取卡片标题「账户余额」；**绝不取「充值」按钮名**。只有右键**单点**「充值」按钮时，才出充值 PRD |
| **曾经的错误（防回归）** | 框整卡时把区域名误判为「充值」，把整卡当成充值功能点。判 FAIL |

### RT-03　框「整个首页数据看板」→ 按板块分组列各卡字段

| 项 | 内容 |
|---|---|
| **场景** | OMS 首页整块数据看板（多卡片：一件代发 / B2B / 退货 / 账户余额 / 商品数量 / 库存） |
| **操作** | 右键**框选**整个数据看板 |
| **预期结果（PASS）** | 按**板块分组**逐卡列字段，用例讲清各板块能看到什么：一件代发、B2B、退货、账户余额、商品数量、库存 各自的字段与口径 |
| **曾经的错误（防回归）** | 输出「切换时间维度 / tooltip 图表」之类的套话，而非真实各卡字段。判 FAIL |

### RT-04　OMS vs WMS 同名功能 → 各自独立 fp_key，口径不混

| 项 | 内容 |
|---|---|
| **场景** | OMS 与 WMS 存在同名菜单 / 功能 |
| **操作** | 分别在 OMS 视图、WMS 视图下框 / 点同名功能 |
| **预期结果（PASS）** | 各自生成**独立 fp_key**（含视图标识）；OMS 用例措辞为「本客户 / 已登录 OMS」，WMS 用例措辞为「全部客户 / 已登录 WMS」 |
| **曾经的错误（防回归）** | 两视图共用一条 PRD / fp_key，或把「本客户」与「全部客户」口径写反 / 混用。判 FAIL |

### RT-05　框选采集完整性 → 真实 DOM + 全字段 + 精确绑定 fpKey

| 项 | 内容 |
|---|---|
| **场景** | 任意卡片 / 区域框选后的采集数据校验 |
| **操作** | 右键**框选**目标卡片，检查采集出的 zoneContext / zoneGroups |
| **预期结果（PASS）** | ① `zoneContext.zoneHTML` 非空（含真实卡片 DOM）；② `zoneGroups` 含**全部字段**（包括「最后更新」）；③ 命中精确绑定时 `zoneContext.fpKey` 有值 |
| **曾经的错误（防回归）** | zoneHTML 为空、字段漏采（尤其漏「最后更新」）、或命中精确绑定却 fpKey 为空。判 FAIL |

### RT-06　结构性保证 → 无精确绑定时绝不按名字模糊猜

| 项 | 内容 |
|---|---|
| **场景** | 框 / 点的元素**没有** `data-annotation` 精确绑定 |
| **操作** | 右键框 / 点一个无精确绑定的元素 |
| **预期结果（PASS）** | `prdMatch` **只认精确绑定**；无精确绑定时不命中已有功能点，转走「真实内容采集 / 待 AI 生成」路径 |
| **曾经的错误（防回归）** | 凭功能名做模糊匹配，错绑到名字相近的已有功能点。判 FAIL |
