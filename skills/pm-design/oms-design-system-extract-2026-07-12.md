## 3. 筛选区 `zgl-search-box`（组合筛选·关键差异点）

- 容器：白底卡片，`padding:16px 16px 0`，`border-radius:6px`，flex 横排。
- **核心是"三段组合控件"（threeWide）**：
  `[left-select 下拉选字段 ▾(140px)] [middle-input 输入值(264px·占位"批量搜索用逗号,隔开"·右侧带🔍搜索图标)] [right-select 精确/模糊搜索 ▾]`
- 其后：`[查询](primary 蓝) [重置](default 白)`。
- 输入内框 `.el-input__wrapper` 高 30px。
- **不是** label+输入的传统排布，是"选字段+填值+匹配方式"的组合。

# 第二轮实测（2026-07-12·页面级结构）

## 9. ⚠️ 发票主体「设置/编辑」= **整页视图，不是弹窗！**

点行内 ✏ → 路由跳 `/invoiceAccount/edit?id=6&tab=company`，**新开一个可关闭页签「编辑发票账号 ✕」**。
**这是骨架的 `detailView` 范式（整页 + 左侧锚点导航），不是 formDialog。**（我原型曾错做成 5tab 弹窗）

**布局**：左侧锚点面板（标题「发票账号」+ 5 个锚点） | 右侧内容卡片 | **底部固定条 `[取消] [提交](primary)`**（sticky footer，始终可见）。

## 13. 税种编辑页（整页 detailView · 6 锚点）`/taxation/edit?id=N&type=sample`

顶部注意事项框：「修改税种时，请咨询专业的税务顾问或会计师，避免因设置错误产生税务问题」

### 13.1 基本信息（2列·全必填）
| 字段 | 类型 | 备注 |
|---|---|---|
| 公司名称 * | select | |
| 税务类型 * | **input 只读灰** | 如 Simples Nacional |
| 交易性质 * | input | 🔴 **带前缀标签**（`[出库]` + 输入框）+ **字数统计 39/60** |

### 13.2 🔴 ICMS/IPI/PIS/COFINS = **重复字段组**（不是简单表单！）
每个税种块里，同一组字段**按「场景」重复出现 N 次**：

| 税种 | 每组字段 | 组数（实测）|
|---|---|---|
| **ICMS** | 场景* / 客户类型* / **CFOP*** / 纳税类型(CST)* | **4 组**（CFOP 实测 6910 / 5910 / 6910 / 5910）|
| **IPI** | 场景* / 客户类型* / CST* / **Código de enquadramento*** / **税率*** / 备注 | **2 组** |
| **PIS** | 场景* / 客户类型* / CST* / 税率* / 备注 | **2 组** |
| **COFINS** | 同 PIS | **2 组** |

场景值示例：`州际交易-出库`；客户类型示例：`法人(Jurídica)`。

### 13.3 其他信息
`补充信息（Fisco）`（textarea·**字数 0/200**）、`补充说明`（textarea·0/200）

## 14. 🔴 发票管理各状态页 **列/工具栏/页签都不同**（我曾错用同一套）

| 状态 | 列 | 出库/入库页签 | 工具栏 |
|---|---|---|---|
| **开票中** | 序列号/发票号/发票账号/key/发票类型/客户/CPF·CNPJ/发票金额/订单号/创建时间（**10列·无状态无操作**）| ✅ | **无** |
| **开票失败** | 同上 10 列 | ✅ | **无** |
| **近期发票** | 上述 9 列 + **状态** + **时间** + **操作**（**12列**）| ✅ | **打印发票 / 开退票 / 开具CC-e / 取消发票 / 导出** |
| **历史发票** | 同近期（12列）| ✅ | 同近期 |

`全部发票账号` `全部状态` `全部发票类型` `全部平台` `全部店铺` `全部异常原因` + `创建时间[开始~结束]` + 组合控件（左下拉默认值随状态变：开票中=**订单号**、失败/近期/历史=**发票号**、异常=**key**）

## 15. 第三轮新发现的组件（骨架需支持）

| 组件 | 说明 |
|---|---|
| **输入框前缀标签** | `[出库] + 输入框`（el-input prepend）|
| **输入框字数统计** | `39 / 60`（el-input `show-word-limit` + `maxlength`）|
| **重复字段组** | 同一组字段按「场景」重复 N 次（ICMS 4组 / IPI·PIS·COFINS 2组）|
| **按状态覆盖页面配置** | 左面板切状态时，**列 / 工具栏 / 页签 / 筛选默认值 都要跟着换**（不只是换数据）|

## 12. 本轮新发现的组件范式（默认规范应支持）

| 组件 | 说明 |
|---|---|
| **整页编辑视图** | 行内✏ → 新页签 + 左锚点 + sticky footer[取消][提交]（**不是弹窗**）→ 骨架 `detailView` |
| **注意事项框** | `el-alert` warning：橙底 ⓘ + 「注意事项：」+ 编号条目 |
| **行内可编辑表格** | 单元格内嵌 select/数字输入/`%`后缀/勾选框/删除图标；表头可带勾选框与 ⓘ 提示 |
| **单选(radio)列** | 如「默认税种」|
| **单元格标签** | 蓝色 tag（如「样品/赠品税种」）|
| **开关规则块** | switch + 主说明 + 灰色副说明 |
| **日期范围** | `[开始时间] to [结束时间]`（真系统中文界面里也显示 `to`）|
| **空状态** | 插画 + 「暂无数据」|
| **左侧状态面板** | 可折叠 + 条目带计数（发票管理用）|

> 骨架已支持：detailView / statusTabs / 组合筛选(combo) / 多选工具栏 / 状态圆点 / 蓝链+✏。
> 骨架**尚未支持**：注意事项框、行内可编辑表格、radio 列、单元格 tag、开关规则块 —— 待按需编码。
