> 1. 🤖 **AI 的输出格式契约**：AI 反推/出方案时，按本文件结构输出 `.md`

## 👤 你只填这 4 项

1. **模块名**：（如：会员等级管理 / 商品库）
2. **业务对象**：（如：会员等级 / 商品 / 订单）
3. **部署地区**：CN / 海外 / 多地区
4. **工作方式**（4 选 1）：
   - □ **方式 1 / 竞品反推融合**：拖竞品截图或链接 + 对话框说"在竞品基础上加 X 减 Y"
   - □ **方式 2 / 现有系统改造**：拖现有截图 + 对话框说"在 X 处加 Y" → AI 主动出新功能排版
   - □ **方式 3 / AI 主动出方案**：你不知道怎么做 + 没竞品 + 没现有系统 → 对话框只说模糊需求 → AI 扮演资深 PM 出业务架构方案
   - □ **方式 4 / 文档分析 + 系统建议**（两阶段）：发客户需求文件 / 产品大纲 / RFP → AI **先出业务分析方案**（业务/系统类型/MVP/技术栈/风险/待澄清）→ 你确认方向 → AI 再出原型

## 🤖 AI 反推后必出的核心内容

AI 输出的 `画原型+写PRD提示词-<模块>-<日期>.md` 必须包含：

### §A0 菜单结构 ⭐（PRD 章节命脉 / 必须显眼）

```
<系统视图名>
├── <一级菜单>
│   ├── <二级菜单>
│   │   ├── <三级菜单>（当前模块）
│   │   │   ├── 功能点 1（如：查询）
│   │   │   ├── 功能点 2（如：新增）
│   │   │   └── ...
```

⚠️ **菜单结构是 PRD §4 章节编号的命脉**，必须单独显眼列出让你核对。

### §A1-§A7 业务设计

- §A1 产品形态（B 端/C 端/移动等 14 类形态适配）
- §A2 业务对象 + 字段分组（**只列骨架**：分组名 + 字段名，约束 AI 按 PRD 铁律自动补）
- §A3 功能点（含业务下发 8 类）
- §A4 框架结构（顶栏/侧栏/面包屑/页签/筛选/操作列）
- §A5 视觉风格（标识来源 + 缺失行业标准补全）
  - 主色 / 辅色 / 圆角 / 字体 / 间距 等 token 必标识：
    - `✅ 从竞品抓` — 截图/链接里有的
    - `⚠️ 行业标准补全（待你核对）` — 缺失部分按对应产品形态的行业标准补（详见 SKILL.md Capture Mode 14 类形态行业标准库）
- §A6 交互细节（状态机 + 业务前置 4 类校验）
- §A7 术语 + 角色 + 部署 + 合规 + NFR

### §A8 ⚠️ 不确定点

AI 必须诚实列出拿不准的判断，等你澄清。

## 🤖 7 步分步流程（不一次性出全部 / v1.0 强化）

```
Step 0（拖竞品时必先）: AI 问"视觉规范用哪套？A 默认/B 当次竞品/C learned-specs"→ 你回 A/B/C
Step 1: AI 识别工作方式 → 反推提示词 .md → 你核对（重点核对 §A0 菜单结构 + §A5 规范来源 + §A8 不确定点）
Step 2: 你说 "§AX 改 Y / 加菜单 Z / 删功能点 W" → AI 增量更新 .md（不全文重写）
Step 3: 你说 "按这个画" → AI 出原型 HTML（**研发可直接用 / 5 项铁律**）
Step 4: 你核对原型 → 说 "标题改 / 列加列" → AI 增量改原型
Step 5: 你说 "原型 OK" → AI **主动问范围**："对哪些菜单/功能点写 PRD？默认全部，可指定" → 你回 → AI 按范围出 PRD + prd-data.json
Step 6: 你核对 PRD → 说 "§X.Y 改" → AI 增量改 PRD + 同步原型标注
```

⚠️ **原型必须研发可直接用**（5 项铁律 / Step 3 强制）：① 字段命名对齐后端 ② 组件模块化拆分 ③ 关键业务逻辑有注释 ④ CSS scoped+BEM ⑤ API 调用层 `src/api/*` 封装。详见 [prototype-template.md](./prototype-template.md) §13。

⚠️ **PRD 范围控制**（Step 5 强制）：AI 不能默认全写 PRD。你可以指定 5 种方式：① 全部 ② 按菜单 ③ 按菜单组合 ④ 按功能点细粒度 ⑤ 按排除（除 X 外）/ 按版本（本期 A/B，下期 C/D）。

⚠️ **增量同步铁律**：你改某一处 → AI 只更新 3 处（原型 HTML / prd-data.json / PRD .md 对应段），**不全文重写**，不动无关内容。

⚠️ **菜单改的特殊性**：菜单加/删/改名 → AI 同步 3 处：① 原型侧栏+面包屑 ② prd-data.json menus 节 ③ PRD §4 章节编号自动重排。
