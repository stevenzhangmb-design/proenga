## 0. 两系统关系（实测确认）
**OMS 与 WMS 是同一套设计系统**（令牌、组件范式、列表/详情/工具栏/操作列逐像素一致，仅语言与业务模块不同）。
→ 规范单一：同类组件在两系统、所有模块、所有地区版本必须一致；地区差异只保留本土必需项。

## 1. 顶层菜单树（实测）
- **OMS（简体中文）**：首页 · 订单 · 商品 · 入库 · 出库 · 工单 · 售后 · 物流 · 财务 · 数据 · 设置（11 模块）
- **WMS（葡语）**：Inicial · Clientes · Produto · Entrada · Saída · Ordem de trabalho · Estoque · Pós-venda · Logística · Finanças · Dados · Configurações（12 模块）
- 顶栏右侧：语言切换（简体中文/Portugués/English/Español）、消息角标数、账号下拉（个人中心 / 修改密码 / 退出登录）
- 详情/子页以**多页签**在内容区上方打开（首页 | 模块列表 × | 详情 ×），页签可关。

## 2. 列表页范式（实测：OMS 订单/商品，WMS 商品/客户）
**结构自上而下**：筛选区卡片 → 页签或左导航（状态）→ 工具栏（已选N + 按钮）→ 表格 → 分页。

### 2.1 查询区（筛选区）
- **无 label**，字段名写在**占位符**里；控件宽、多行铺满卡片宽度。
- 下拉默认文案「全部XX」（全部平台/全部店铺/全部仓库/全部订单状态…）。
- **日期范围** = `[维度下拉▾（如"下单时间"/"创建时间"）] [📅开始时间] to [结束时间]`（"to" 分隔 + 日历图标）。
- **批量搜索三段** = `[字段▾] [⌕ 批量搜索用逗号,隔开] [精确搜索▾]`（真系统 zgl-search-box 组合控件）。
- 末尾按钮：**[查询]（主色蓝底填充）** + **[重置]（白底灰边）**，可跟 `[⟳同步订单]` 等页面级动作。
- 命名铁律：**查询**（禁"搜索"）、**重置**（禁"清空/清除"）。

#### 2.1.1 商品查询条件 = 统一三段组合搜索【强制·默认规范·2026-07-26 用户定】
> **所有页面、任何涉及"商品"的查询条件，一律用这一个三段组合控件**，不再各处写零散的 SKU / 商品名称输入框。
- 三段：`[字段▾] [⌕ 批量搜索用逗号,隔开] [匹配▾]`
  - **字段下拉**（固定 5 项，顺序固定）：`SKU编号 / 商品名称 / 商品条形码 / 参考SKU编号 / 商品别名`（默认选中 SKU编号）
  - **批量输入**：占位符「批量搜索用逗号,隔开」，前缀 ⌕ 图标
  - **匹配下拉**（固定 3 项）：`精确搜索 / 模糊搜索 / 前缀搜索`（默认精确搜索）
- 骨架写法（`prototype-skeleton.html` 已内置 `type:'combo'`）：
  `{ type:'combo', label:'SKU编号', fields:[SKU编号,商品名称,商品条形码,参考SKU编号,商品别名], match:[精确搜索,模糊搜索,前缀搜索], ph:'批量搜索用逗号,隔开' }`
- 一致性：库存策略 / 库存分配 / 分销库存统计 / 分销商品 等所有商品列表页统一走此控件。

#### 2.1.2 列表"商品信息"单元格 = 统一标准卡片【强制·默认规范·2026-07-26 用户定】
> **所有列表里"商品信息"列，一律用同一张卡片**（缩略图 + 四行文本），不再各处写不同格式。
- 结构：`[缩略图 No photo]` + 四行：`编号：<SKU蓝色链接>` / `名称：<商品名，超长两行截断>` / `条码：<barcode>` / `参考：<refSKU 或 -->`
- 缩略图：44×44 圆角，无图时显示占位「No photo」；编号用主色 #3363FF。
- 一致性：分销库存统计、买断申请/退回、分销商品 等所有含商品的列表统一此卡片。

### 2.2 状态位置：两种，按状态数量选
- **状态多**（订单：全部654/待处理103/待开票26/待安排/待发货/待揽收/已发货/已取消/已搁置/未付款/异常）→ **左侧导航列**，每项右侧带计数。
- **状态少**（商品：已启用(3682)/已停用(11)；客户：全部(13)/待审核/已通过/已驳回/已启用/已停用）→ **表格上方页签**，页签带计数。

### 2.3 工具栏（表格上方一行）
- 左：`已选 : N` + 主操作按钮组；右：单位切换 `公制|英制` + `导入` + `导出`。
- **新增类按钮永不禁用**（任何时候可点）；批量类（删除/停用等）未勾选时禁用。

### 2.4 操作列
- **一律图标**（👁查看 + 编辑 + 打印…），蓝色 `rgba(51,99,255,.8)`，带 tooltip，**不是文字链接**。

### 2.5 表格单元格
- 可点单元格（订单号/客户号/SKU）= **蓝链 `#3363FF`**（点开详情整页）。
- 状态列 = ●圆点 + 彩色文字（绿=正常/已授权，红=失败/过期，灰=创建中）。
- 标记(标签) = 单元格内**可删除彩色 chip**（如「99999黄色 ×」「红色 ×」）。
- 分页：右对齐 `共N条 · [10条/页▾] · ‹ 1 2 3 … › · 前往[ ]页`。

## 3. 查看详情页范式（实测：OMS 订单详情，WMS 客户详情）—— 只读
- **整页新页签**打开（路由 `/detail` 或 `/view`），**不是弹窗**。
- （过程型实体，如订单）顶部有**横向状态步骤条**：`待处理①→待开票②→待安排③→待发货④→待揽收⑤→已发货⑥`，当前步蓝色高亮，每步下带**时间戳**。
- 内容按**分区标题**分组（基本信息 / Informações Básicas…）；可编辑区标题带 ✎ 铅笔，纯查看区无铅笔。
- 字段：**3 列网格**，**label 在上（灰色 muted）、值在下**；空值显示「--」。
- **底部：居中的单个 `[返回]`/`[Voltar]`**（白底灰边）。**只读查看绝不是 `[取消][提交]`。**

## 4. 新增 / 编辑表单范式（实测：WMS 新增商品 `/goods/goodsManage/add`）
- **整页新页签**打开（页签「新增商品 ×」，路由 `/add`），**不是弹窗**。
- 分区标题（**基本信息** 加粗）分组字段。
- 字段 **3 列网格**、**label 在上**（label 在输入控件上方，非行内 label）。
- **必填** = label 后红色 `*`（客户*/商品名称*）。
- **帮助提示** = label 后灰色 `?` 圆图标（参考SKU编号 ? / 商品别名 ? / 条形码 ?）。
- 占位符：下拉「请选择」、输入「请输入」、可自动生成的「不输入将自动生成」。
- **多值字段**（条形码）= `[＋ 添加]` 按钮，点了增行。
- **图片上传** = 大方块 `+` 拖拽区 + 下方灰字格式提示（"支持JPG、JPEG、PNG、BMP格式，单个文件大小不超过5M，最多上传10个文件"）。
- **底部：居中 sticky `[取消][保存]`** —— 取消(白底灰边) + 保存(主色蓝底)。
- **⚠️ 实测修正（2026-07-26）**：新增表单底部是**「保存」，不是「提交」**。旧 `system-design-spec.md §5.3`/`prototype-skeleton` 写的 `[取消][提交]` 至少对「新增商品」是**错的**——这正是导致我画原型底部按钮漂移的规范错误来源。**待办：核对是否所有新增/编辑都用「保存」，还是个别流程（如税种详情/新增向导）用「提交/继续」，把差异钉清。**

## 5. 弹窗（Dialog）范式（2026-08-02 CDP 实测·原 0 实测已补齐）
真系统弹窗分两类：
- **① 二次确认（el-message-box）** —— 删除 / 审批 用。**宽 480px** · 标题 + 一句提示 + 底部 `[取消][确定(主色)]`。
  - 客户「审核不通过」实测：title「Reprovado Clientes」· body「确认驳回该客户？」· `[取消][确定]` —— **🔴纠正：无"驳回原因"输入框**（我之前按 §4.4 推断"驳回必填原因"是错的·至少客户审批=纯确认）。
  - 客户「审核通过」同类纯确认。
  - **删除有状态前置条件**：状态不符→**不弹确认框、弹拦截 toast**（商品「只有待审核/已驳回可删」·物流方式「只有停用可删」）→ **印证 §5.3t 权限拦截范式**（按钮不藏·点了给提示）。状态符合才弹 el-message-box 确认。
- **② 表单/选择弹窗（el-dialog）** —— 标记 / 新增子项 等带内容的。**标记弹窗实测：宽 580px · 圆角 4px** · 顶部搜索(Buscar/Limpar) + **分组可选标签**(分类 / 商品状态 / 入库作业类·彩色 chip 点选) + 底部 `[取消][确定(主色)]`。
- 令牌：确认框 480px / 表单弹窗 580px · 圆角 4px · 主操作蓝底、取消白底。

## 7. 共性操作范式总纲【每类操作唯一标准·画原型照此·禁自由发挥】
> 用途：任何模块的同类操作**长一个样**。以后画默认原型，每类操作只准用下面这一个范式，不许每页自己编。
> 标注：✅=已实测坐实；🟡=按钮名/规范先例高置信推断，**待一次干净实测坐实 dialog 内部**（禁当已证）。

| 操作 | 唯一标准范式 | 证 |
|---|---|---|
| **菜单** | 顶部横向主菜单（各模块），悬停展开**多列分组大菜单**；内容区上方多页签（列表×/详情×可关）。另有经典左侧栏模式可切。 | ✅ |
| **查询条件** | 筛选区卡片·**无 label·字段名进占位符**；下拉默认「全部XX」；日期=`维度下拉+[开始]to[结束]`；商品=统一三段组合搜索(§2.1.1)；末尾`[查询蓝底][重置白边]`。**禁"搜索/清空"叫法。** | ✅ |
| **列表** | 筛选区→状态(多=左导航列带计数/少=页签带计数)→工具栏(`已选:N`+主操作，新增类永不禁用)→表格→分页。操作列**一律图标**(👁查看/编辑/打印)非文字。可点单元格=蓝链。 | ✅ |
| **新增** | **整页新页签**(路由`/add`)·分区标题·**3列 label在上**·必填红`*`·帮助灰`?`·占位「请输入/请选择」·底部居中 sticky **`[取消][保存]`**(保存主色)。**不是弹窗、不是「提交」。** | ✅ |
| **编辑** | 同「新增」布局·字段**回显**已有值·路由`/edit`·底部 `[取消][保存]`。实测(商品编辑31字段)：比新增多**只读回显 meta**（Status/创建人/创建时间）。 | ✅实测 |
| **删除** | **不进整页**：行内🗑或勾选后工具栏「删除」→ **二次确认框**(el-message-box：「确认删除该XX？」+`[取消][确定]`)→ 成功 toast「删除成功」+列表刷新。查询/查看不产日志、删除产操作日志。 | 🟡(按钮名✅·确认框文案待实测) |
| **查看** | **整页新页签**(路由`/detail`或`/view`)·(过程型实体)顶部**横向状态步骤条带时间戳**·分区标题·**3列 label在上只读回显**(空值`--`)·底部**居中单个`[返回]`**。**绝不是弹窗、绝不是`[取消][提交]`。**（发票系统查看页漂在这——没步骤条/字段乱排/底部错） | ✅ |
| **审批通过** | 勾选待审核行→工具栏**「审核通过」**→(通常)二次确认框→成功 toast+状态转「已通过/已审核」+通知申请人。 | 🟡(按钮名✅·弹窗待实测) |
| **审批不通过** | 勾选待审核行→工具栏**「审核不通过」**→**el-message-box 二次确认**「确认驳回该客户？」`[取消][确定]`→状态转「已驳回」。**🔴实测纠正：客户审批无"驳回原因"输入框**（我原按 §4.4 推断必填原因是错的）。其它模块是否有原因字段=未实测·别假设。 | ✅实测(客户) |

**画原型自检**：每画一个查看页→必有(整页+步骤条[过程型]+3列只读+居中返回)；每画新增/编辑→必是(整页+3列+`[取消][保存]`)；删除/审批→必走(勾选/行内→确认框或原因弹窗→toast+状态变)。缺任一即偏离真系统。
