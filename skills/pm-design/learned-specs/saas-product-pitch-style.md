# SaaS 售前产品方案 PPT 风格（学习自另一标杆 WMS + 行业标杆 WMS）

> 📚 **来源**：另一标杆 WMS 产品介绍 (19 页) + 行业标杆 WMS 产品介绍 (34 页 / 店小秘旗下)
> 📅 **学习日期**：2026-06-07
> 🎯 **用途**：作为 product-pitch skill 生成"售前产品方案"的标杆模板

---

## 共性结构（两份案例提炼）

### 4 大部分（标准框架）

```
01 关于公司 / 产品（公司可信度）
02 行业痛点 & 业务场景（共鸣）
03 全面领先的解决方案 + 功能亮点（产品力 / 主体）
04 为什么选择我们（决策助推 / CTA）
```

### 视觉风格

- 主色蓝色（B 端 SaaS 标配）+ 大留白
- 大字号标题 + 小字号正文
- 数据用大数字（如 `320W+` / `99%` / `53%`）
- 图标矩阵 + 流程图 + 中心辐射图

## 标杆水准（行业标杆 WMS 34 页结构）

### 开场（2 页）
- P1 封面：Logo + 一句标语（如"简洁、专业的B 端管理系统"）+ 全屏蓝色
- P2 目录：4 大模块（01-04 编号 + 模块名）

### 第一部分：关于公司 + 生态（7 页）
- P3 章节封面（大号编号 + 模块名）
- P4 关于（简介 + 6 个关键数据 + 4 个荣誉 + 投资方）
- P5 产品布局生态（世界地图 + 子产品矩阵 + 用户数据）
- P6 发展历程（时间轴 + 用户增长曲线）
- P7-9 已对接的 ERP / 电商平台 / 物流（logo 矩阵）

### 第二部分：痛点 + 业务流程（6 页 / 行业标杆独特强项）
- P10 章节封面
- P11 B 端管理难题（4 大场景，每场景 4-5 个痛点）
- P12 一件代发业务流程（WMS 端 + OMS 端 + 角色 + 闭环图）
- P13 FBA 退货业务流程（4 个子流程矩阵图）
- P14 B2B 转运业务流程
- P15 代理仓业务流程

### 第三部分：解决方案 + 功能亮点（13 页 / 主体）
- P16 章节封面
- P17 系统介绍（200 字介绍 + 6 个核心数据 + 价值定位）
- P18 八大核心产品功能 + 5 个量化效果（99%/53%/99%/70%/39%）
- P19 系统功能矩阵（WMS / OMS 两端 / 全功能模块）
- P20 业务场景全景图（中心辐射 5 大模式）
- P21-29 每模块功能亮点页（9 页）：
  - 一件代发：中心环绕 / 8 大功能
  - B2B 转运：菱形布局 / 4 大功能
  - FBA 退货：流程图 + 4 个亮点
  - 代理仓：流程图 + 4 个亮点
  - 分销业务：4 个亮点
  - 计费管理：功能截图 + 4 个亮点
  - 仓内管理：功能截图 + 4 个亮点
  - 物流管理：功能截图 + 4 个亮点
  - 数据报表：功能截图 + 4 个亮点

### 第四部分：为什么选我们（4 页）
- P30 章节封面
- P31 产品优势（6 大优势 / 3×2 网格图标）
- P32 服务优势（6 大优势 / 六边形中心放射）
- P33 资源优势（3 大优势 / 山字形）

### 收尾（1 页）
- P34 Logo + 标语 + 二维码 + 官网

## 关键设计模式（可复用）

### 1. 数据呈现公式
`<大数字> + <单位> + <一行说明>`
例：`320W+ 服务全球用户` / `99% 订单履约及时率` / `53% 人效提升`

### 2. 功能亮点描述公式
`<加粗能力名>（4-6 字）+ <一句话价值描述>（15-25 字）`
例：
- "**智能波次打单**：缩短拣货路径，提升出库效率"
- "**多种打单模式出库**：简易、波次打单，优化商品出库效率"

### 3. 业务流程图模式
- 横向时间线（入库 → 收货 → 上架 → 出库）
- 角色框（收货员 / 上架员 / 拣货员 / 打包员）
- 系统端框（OMS 端 / WMS 端 / 卖家 / 买家）

### 4. 业务场景命名（不是模块名）
- ✅ 一件代发 / 备货中转 / 退货换标 / 代理仓
- ❌ 出库管理 / 入库管理 / 退货管理

### 5. 章节封面模式
- 全屏蓝色 + 大号编号（01-04 描边字）+ 大字号模块名
- 仅 1 行内容 / 全图形冲击

## 适合的产品形态

按本风格生成的售前方案，**适合**：
- ✅ B 端 SaaS（ERP / WMS / OMS / CRM / HR / 财务等）
- ✅ 行业垂直 SaaS（物流 / 制造 / 零售 / 教育等）
- ✅ B2B 平台
- ⚠️ C 端产品（需要调整：少业务流程图 / 多生活场景图）
- ⚠️ 移动 APP（需要调整：APP 截图 vs 后台截图）
