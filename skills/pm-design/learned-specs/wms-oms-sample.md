## §A5 导航框架

### 顶部导航栏（Top Navbar）

```
高度：56px
背景：#0E1729（深蓝黑）
布局：[Logo] [一级菜单...] [右侧：语言/通知/头像+用户名]
```

**一级菜单规则：**
- 文字颜色：白色
- 激活态：蓝色文字 + 下方蓝色下划线 + 背景微亮
- Hover：显示**悬浮下拉 Mega Menu**（多列，按业务分组）

**Mega Menu 结构：**
```
| 分组标题（灰色小字）| 分组标题 | 分组标题 |
| 子菜单项（蓝色）   | 子菜单项 | 子菜单项 |
| 子菜单项           |          |          |
```
- 背景：白色，有阴影
- 激活子菜单：蓝色文字

### 页签导航（Multi-Tab）

列表页：面包屑模式 `首页 > 客户管理`

详情/新增页：**可关闭 Tab 标签页**模式
```
[首页] [客户管理 ×] [新增客户 ×]    [×关闭全部]
```
- Tab 有 × 关闭按钮
- 激活 Tab：`background:#F2F2F2`（灰底）+ `color:#3363FF`（蓝字）+ `border-radius:4px 4px 0 0`
- ⚠️ **不是蓝色底色！** 是灰底 + 蓝文字（实测纠正）
- 非激活：白色底色，`#303133` 文字

### 内容区 Tabs（状态筛选）

用于列表页内按单据状态分组：
```
[全部 (0)] [待发货 (0)] [已发货 (0)] [已取消 (0)] [异常 (0)]
```
- 激活：`background:#F2F2F2`（灰底）+ `color:#3363FF`（蓝字）+ `font-weight:500`
- ⚠️ **不是蓝色下划线！** 实测为灰底蓝字（多工作台和内容 Tab 样式完全相同）
- 非激活：`color:#303133` 灰色文字，白色背景

```css
/* Tab 实测样式 */
.tab-item { height:40px; padding:0 20px; line-height:40px; font-size:14px; color:#303133; cursor:pointer; }
.tab-item.active { background:#F2F2F2; color:#3363FF; font-weight:500; border-radius:4px 4px 0 0; }
```

```
┌─────────────────────────────────────────────────┐
│ [面包屑 / Tab 页签]                              │
├─────────────────────────────────────────────────┤

│  ├──────────┤ ├──────────┤ ├──────────┤        │
│  │ 输入框    │ │ 下拉框    │ │ 输入框    │        │
│  ├──────────┴─┴──────────┴─┴──────────┤        │
│  │ 日期范围：[开始时间] to [结束时间]   │        │
│  ├─────────────────────────────────────┤        │
│  │              [查询] [重置]           │        │
│  └─────────────────────────────────────┘        │
├─────────────────────────────────────────────────┤
│ 状态 Tabs（可选）                                │
├─────────────────────────────────────────────────┤
│ 操作栏                                           │
│ 已选:0  [新增▲] [删除] [启用] [停用] ... [↑导出]│
├─────────────────────────────────────────────────┤
│ 数据表格                                         │
│  □ | 编号 | 名称 | ... | 状态 | 创建人 | 时间 | 操作 │
│  □ | IZU007 | 姜橙子... | ... | 已启用 | ...  | 👁🔒🔗 │
├─────────────────────────────────────────────────┤
│              Total 7  10/pagina  < 1 >  Ir para 1│
└─────────────────────────────────────────────────┘
```

**筛选区细节：**
- 3 列等宽网格
- 日期范围单独占一行（宽输入）
- 查询按钮：蓝色填充；重置按钮：白色边框
- 卡片圆角 4px，内边距 16-20px

**操作栏细节：**
- 左侧：`已选: N` 计数器（灰色文字）
- 主操作：新增（蓝色填充按钮）
- 次要操作：删除/启用/停用（白色边框按钮）
- 业务操作：审核通过/审核不通过（白色边框按钮）
- 右对齐：导出（带上传图标）

**表格操作列（图标按钮）：**
- 查看：👁 eye 图标（蓝色）
- 编辑/授权：📋 / 🔒 图标（蓝色）
- 关联：🔗 链接图标（蓝色）
- 无文字，hover 时显示 tooltip

**分页：**
- 右对齐
- 格式：`Total N  10/pagina  ‹ 1 ›  Ir para [1]`
- 葡语标签（pagina / Ir para）

## §A7 组件规范

### 按钮

| 类型 | 样式 | 场景 |
|---|---|---|
| Primary | 蓝色填充 `#3B7DFF`，白字，4px 圆角 | 新增、查询、提交 |
| Default | 白底，灰色边框，灰色文字 | 删除、重置、取消 |
| Text | 无边框，蓝色文字 | 表格操作图标按钮 |
| Danger | 红色填充或白底红字 | ⚠️ 行业补（未截到） |

### 输入框 / 下拉框

- 高度：32px
- 边框：1px solid `#DCDFE6`（Element Plus 默认）
- Focus 边框：`#3B7DFF`
- 圆角：4px
- placeholder 颜色：`#C0C4CC`

### 状态标签（Status Tag）

表格中状态文字（已启用/已停用/已审核）：
- **纯文字**（非 el-tag），无背景色
- 已启用：默认文字色
- 已停用：灰色
- 异常数值：红色 `#F56C6C`

### 表格

- 表头：背景 `#F7F8FA`，文字色 `#999999`，字号 **13px**（实测），font-weight 600
- 行文字：色 `#444444`，字号 **12px**（实测，非 14px）
- 行内边距：`padding:8px 12px`（实测，非 13px/16px）
- 行分隔：`border-bottom:1px solid #EBEEF5`
- 行高：实测约 36px（含 8px 上下 padding）
- 奇偶行：无斑马纹（纯白）
- 边框：横线（无竖线，原生 table 实现）
- 选择列：左侧 checkbox
- 单据编号：`color:#3363FF`，fontWeight 400（非粗体！实测纠正）

```css
/* 表格实测样式 */
.pt th { background:#F7F8FA; color:#999999; font-weight:600; font-size:13px; padding:8px 12px; border-bottom:1px solid #EBEEF5; }
.pt td { padding:8px 12px; border-bottom:1px solid #EBEEF5; color:#444444; font-size:12px; vertical-align:middle; }
```

### 操作列图标（两种模式）

**Pattern A（财务/OMS 页）**
- PNG via el-image，`rgba(51,99,255,0.8)` 蓝色
- 尺寸 20x20px，border-radius 4px
- hover：`color:#3363FF; background:rgba(51,99,255,0.08)`
- danger hover：`color:#F56C6C; background:rgba(245,108,108,0.08)`

**Pattern B（仓储/WMS 页）**
- SVG sprite，`#333333` 灰色
- 尺寸 18x18px

### 状态标签

**平台状态标签**（如"速卖通"渠道状态）：
```css
.platform-status { display:inline-block; font-size:12px; border-radius:2px; padding:0 8px;
  border:1px solid #E61F11; background:rgba(230,31,17,0.06); color:#E61F11; }
```

**来源标签**（手动创建 / API对接）：
```css
.source-tag { background:#EEEEEE; color:#444444; border-radius:0; padding:1px 10px; font-size:14px; }
```

### 空状态

- 居中插图 + 文字
- 分页仍显示（Total 0 / 10/pagina）

## §A13 复用建议

画 WMS/OMS 原型时应遵守的特殊规则：

1. **顶部导航** 替换侧边导航——所有模块通过顶栏 Mega Menu 进入
2. **多 Tab 页签** 作为详情/表单页的导航方式（浏览器 Tab 风格，灰底蓝字激活）
3. **3 列表单** 作为所有表单页的默认布局，inputs 用 box-shadow inset
4. **分页用葡语标签**：`Ir para`、`pagina`（面向巴西运营人员）
5. **顶栏颜色** 用 `#122041`（实测精确值）
6. **操作列用图标按钮**（不用文字按钮），hover tooltip 显示操作名
7. **表格字号**：表头 13px，行 12px（比 Element Plus 默认小）
8. **筛选区输入框**：高度 30px（比默认 32px 小）
